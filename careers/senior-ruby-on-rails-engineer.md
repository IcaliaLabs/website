## About the role

Icalia Labs is hiring a Senior Ruby on Rails Engineer with deep expertise in building scalable, production-grade APIs and a strong foundation in modern backend engineering. We're looking for engineers who go beyond implementation — professionals who understand how systems behave under load, how databases perform at scale, and how to design APIs that last. This is a remote contractor engagement working CST hours.

## What you'll do

-   Design and build high-performance APIs using Ruby on Rails.
-   Write optimized PostgreSQL queries and deeply understand how data flows and scales under production load.
-   Implement and maintain asynchronous and background processing systems (Sidekiq, Resque, or equivalent).
-   Ensure code quality through robust RSpec testing strategies and solid automated testing practices.
-   Apply best practices for API design, scalability, and long-term maintainability.
-   Collaborate on architecture decisions and continuously improve system performance.

## What we're looking for

-   8+ years of software engineering experience or equivalent practical background
-   Strong expertise in Ruby and Rails APIs in production environments
-   Clear understanding of how databases work and how to write efficient PostgreSQL queries (indexing, query optimization, performance tuning)
-   Hands-on experience with background job processing systems (Sidekiq, Resque, or similar)
-   Solid knowledge of AWS and Docker for cloud infrastructure and containerized environments
-   Strong grasp of API best practices and backend architecture
